# v0.1: a playable alpha

v0.1 is reached when a small group can play an evening of HL2RP on a dedicated server, and the
staff running it never have to leave the game or edit a file to keep it going.

Every line below is either checked by a command or by a named person doing a named thing. If it
cannot be checked, it does not belong here. When all are ticked, merge `rewrite/game-first` to
`main` in both repositories and tag `v0.1.0`.

## 1. It holds to its own laws

Checked by `pwsh tools/verify.ps1`, `pwsh tools/playtest.ps1` and `pwsh tools/playtest-server.ps1`,
all passing on the commit being tagged.

- [x] A client is never sent another character's name or faction it was not told.
- [x] Speech stops at its range, and a claimed position buys no reach and no hearing.
- [x] Items and tokens only move: every source and sink is named, and the token supply equals the journal's issues minus its destroys.
- [x] Every host decision, refusal and staff command is in the journal.
- [x] Characters, what they know, their state, holders and doors survive a restart.
- [ ] The two-client test passes three runs in a row. One earlier run judged a character from the wrong place and the cause was never found; this is how it is ruled out or caught.

## 2. A person can play it without being told the keys

Checked by Noah playing the scene alone for fifteen minutes and ticking each line. Nothing here
has ever been clicked by a person; every test so far drove the game through `DevCommands`.

- [ ] Create a character, enter the city, and leave it.
- [ ] Say, whisper, yell, emote and talk out of character, and read the replies.
- [ ] Move, hold, use and drop items; pick one up; put one in the crate and take it back.
- [ ] Buy from and sell to the vendor, and see each price before paying it.
- [ ] Open, lock and buy a door.
- [ ] Find every verb a target offers, and choose one deliberately, from a menu: not from memory of number keys.
- [ ] Open the staff panel, read the journal, and move a character.
- [ ] No panel traps the cursor, swallows a key, or has to be closed by restarting.

## 3. What the old game had that an evening needs

Each arrives the way everything else did: as a playable slice with its own play-test section.

- [ ] **Stacks.** Identical items share a slot up to a limit set on the item. Splitting and merging are transfers and are journaled. A pistol and thirty rounds fit in a starting inventory.
- [ ] **Radio.** Holding a radio tuned to a frequency carries speech to others holding one tuned the same, and to nobody else. Someone standing next to the speaker hears it as ordinary speech.
- [ ] **Looks.** A faction sets its members' model. An item asset sets the model it has in the world and in hand. A downed character, a body, a crate and a vendor are not boxes.
- [ ] **What is in hand is seen.** A second player can tell, by looking and without a test driver, that someone has drawn a pistol.

## 4. It runs somewhere that is not Noah's PC

Checked once, by Noah and at least two other people on their own Steam accounts.

- [ ] `sbox-server` hosts HL2RP on a machine nobody is playing on, and three accounts join over the Steam relay, not loopback.
- [ ] A one-hour session ends with no exception and no `[store]` or `[journal]` warning in the server's output.
- [ ] Staff whitelist an account, give an item, move a character and settle one dispute from the journal, without touching the server's console or its files.
- [ ] The server is stopped and started mid-session and everyone returns to where, and how, they were.
- [ ] The data folder is copied while the server runs, and a server started on the copy loads every character.

## 5. Someone else could pick it up

- [ ] The README's setup steps, followed exactly on a clean checkout, end in a running game.
- [ ] Unit tests run on every push, on a hosted runner. The play tests stay local, because they need s&box.
- [ ] `docs/decisions.md` has no entry that the code contradicts.

## Not in v0.1

Deliberately left for later, so their absence is not a reason to hold the tag: the scanner, civic
records, forcefields, ration dispensers and the Combine overlay (HL2RP's own work); recoil, cover
and a restraint struggle; whitelist applications in game; an operator view of the money supply;
journal rotation; migrating saved data across a schema change; a second game built on the library;
publishing `kbj.hexagon` as a package. The last two are what v1.0 is for.
